# Alcance funcional

## Contexto

El proyecto académico aborda la digitalización de la gestión de una casa de repuestos automotores. Según el relevamiento documentado, antes del sistema varias tareas se registraban manualmente en carpetas y cuadernos: ventas, cobros, inventario y seguimiento de operaciones.

El relevamiento incluyó una entrevista presencial con el responsable del comercio. Para proteger su privacidad, este repositorio omite dirección, datos de contacto y cualquier otro dato que permita identificarlo.

## Necesidades identificadas

- Registrar productos y consultar información del catálogo.
- Mantener actualizado el stock.
- Registrar compras y asociarlas con proveedores y productos.
- Registrar ventas, clientes, medios de pago y descuentos.
- Consultar historiales de ventas y compras.
- Gestionar clientes, proveedores y usuarios.
- Diferenciar permisos según el rol de usuario.
- Consultar información de gestión, como stock y movimientos.

## Módulos descriptos en el manual

| Módulo | Alcance documentado |
|---|---|
| Productos y stock | Alta y consulta de productos, categoría, precio, cantidad disponible, imagen y descripción. |
| Compras | Registro de compras con usuario, proveedor, fecha, costo, productos y cantidades; consulta del historial. |
| Ventas | Registro de ventas con cliente, usuario, fecha, medio de pago, cuotas, descuentos y productos; historial e impresión de comprobante. |
| Clientes | Alta, consulta y modificación de datos de clientes. |
| Proveedores | Alta, consulta y modificación de datos de proveedores. |
| Usuarios | Administración de usuarios y asignación de roles. |
| Paneles | Opciones diferenciadas para perfiles Gerente y Vendedor. |

## Roles

La documentación contempla dos perfiles:

- **Gerente:** acceso a funciones de administración y consulta de información de gestión.
- **Vendedor:** acceso a las funciones operativas habilitadas para ese perfil.

Los permisos concretos se describen en el manual de usuario del proyecto académico.

## Flujo general de trabajo

1. Registrar productos, categorías, proveedores y usuarios necesarios.
2. Registrar compras e ingresos de mercadería.
3. Consultar y actualizar la información de stock.
4. Registrar ventas y los datos asociados a cada operación.
5. Consultar historiales y reportes disponibles.

## Alcance y estado

Este repositorio presenta documentación descriptiva de un proyecto académico realizado en equipo. No representa un servicio comercial actualmente desplegado ni incluye código fuente. Las funcionalidades enumeradas corresponden al alcance y al manual documentados en el trabajo final.
