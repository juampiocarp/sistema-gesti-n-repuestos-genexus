# Sobre este portfolio

- Proyecto académico: Sistema de Gestión para Casa de Repuestos.
- Carrera: Tecnicatura Superior en Desarrollo de Software.
- Institución: Instituto Superior Brigadier López.
- Trabajo realizado en equipo de dos integrantes.
- El aporte individual se describe en el README del repositorio, distinguiendo análisis funcional, relevamiento, modelado, trabajo en GeneXus, diseño de interfaces y colaboración en pruebas.

## Material de origen

La descripción se elaboró a partir del trabajo final y su manual de usuario. Se priorizó resumir el alcance documentado y evitar reproducir información privada del comercio.

## Privacidad

No publicar el PDF académico completo. Contiene información identificatoria del comercio y detalles del relevamiento. Tampoco publicar credenciales, datos de clientes, proveedores, usuarios, correos, teléfonos, direcciones, CUIT, DNI ni bases de datos reales.

## Código fuente

Este repositorio no incluye código fuente del sistema. La presentación documenta el proyecto y el trabajo realizado; no debe interpretarse como un repositorio de implementación.
